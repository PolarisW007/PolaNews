# PolaNews 运行修复 SDD

实测 /api/trending 每次同步调用模型，耗时 16.4 秒，12 秒 Harness 超时。复用服务内缓存模式，将关键词统计和模型增强分开；冷启动 SELECT 最多 200 行并返回现有词频降级结果，同窗口首读和模型刷新均合并。缓存至多 4 项，过期刷新间隔 5 分钟；后台模型沿用现有 90 秒超时，失败仅记录错误类别。

测试用可控 query/LLM/时钟依赖运行实际 TypeScript 模块，覆盖冷请求不等待模型、并发合并、后台成功、过期保留旧结果、模型失败退避、容量界限。

浏览器进一步复现：首页搜索跳转 /search?q=AI 后显示空输入框且不发搜索请求。搜索页订阅 URL 参数并触发原有搜索函数，使用 Suspense 保持构建兼容。Header 原 /login 没有返回路径，改用统一中心现有登录入口并携带 next；不变更凭据与 SSO 协议。

生产使用独立 staging 目录构建、deploy doctor --release 校验，构建期禁止 scheduler。备份当前 trending.ts 与 .next 后进行短时 Supervisor 停止/产物切换/启动；保留生产已有其他修改。失败恢复旧构建与源文件，启动并复查文章、静态资源、RSS、趋势与错误日志。Nginx 本次无改动。
