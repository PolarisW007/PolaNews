# 2026-06-14 本地字体选项扩展需求

## 原始需求

用户要求在 PolaNews 设置中新增 HarmonyOS Sans、纳米松木黑、思源黑体 Adobe 简体中文修正版、Alibaba PuHuiTi 3、vivo Sans 五种字体选择。

## 目标

- PolaNews 设置页新增字体选择区。
- 选择字体后立即应用到全站，并保存到现有 `font_family` 偏好。
- 页面初始化时读取本地/服务端偏好并恢复字体。

## 非目标

- 不新增数据库字段。
- 不改变已有主题、订阅、Digest 推送和密码设置逻辑。

## 验收标准

- 设置页可选择五个新增字体。
- 选择后 `body` 使用对应字体栈。
- `npm run build` 通过。
