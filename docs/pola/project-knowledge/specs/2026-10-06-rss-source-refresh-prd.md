# RSS 检索与状态刷新 SPEC
日期：2026-10-06

现有源保持名称、分类、订阅和历史内容。官方迁移地址在实际解析成功后替换原地址。真实抓取成功才设置active；HTTP拒绝、连接超时、无效XML等保持error并由现有指数退避管理，不因网页搜索可见就标记可用。

抓取传输修复仅影响后台网络行为，源管理及文章入口接口保持兼容。执行人工检查使用fetch_only，限流分批，不额外启动LLM/TTS。来源检索以官方RSS说明和实际服务器响应为依据。对停更源、不可达源分别记录，避免误将过期内容表述为最新内容。

验收覆盖57源最终状态、地址变更前后、失败分类、条目数量和最新时间；使用已有源列表HTTP响应核验用户可见状态。UI布局无改动，以API真实响应作为界面数据证据。
