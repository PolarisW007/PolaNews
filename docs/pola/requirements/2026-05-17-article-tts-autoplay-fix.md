# PolaNews 文章摘要朗读连续播放修复需求

## 背景

文章详情页 `朗读摘要` 存在音频生命周期问题：

1. 正在朗读时点击上一篇/下一篇，旧音频不会立即停止。
2. 切到下一篇后再次点击朗读，会出现上一条和当前条声音重叠。
3. 当前摘要朗读完成后，应自动切换到下一篇继续阅读。

## 需求口径

- 文章详情页同一时间只能存在一个摘要朗读音频。
- 任意文章导航动作都必须先停止当前 `HTMLAudioElement` 和浏览器 `speechSynthesis`。
- 点击朗读前必须先停止旧音频，避免重叠。
- 当前文章朗读自然结束后，如果存在下一篇，应自动跳转下一篇。
- 用户手动停止朗读时，不触发自动下一篇。

## 验收标准

| 编号 | 验收项 | 验证方式 |
| --- | --- | --- |
| A1 | 播放中点击下一篇，旧音频停止 | 浏览器回归 |
| A2 | 到下一篇再次点击朗读，不和旧音频重叠 | 浏览器回归 |
| A3 | 朗读自然结束后自动进入下一篇 | 浏览器/API + 代码审查 |
| A4 | 返回、上下篇、底部导航、相关文章导航都复用同一停止逻辑 | 代码审查 |
